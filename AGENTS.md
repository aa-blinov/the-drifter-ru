# AGENTS.md, контекст агента для `the-drifter-ru`

Русская локализация The Drifter: 9 803 строки в `translation/Russian/translation.csv`
и пайплайн, который их производит.

## Запуск / сборка / тесты

Зависимости скриптов, которые читают шрифты и ассеты игры:
`python3 -m pip install -r requirements.txt`. Сам пайплайн работает на
стандартной библиотеке.

```bash
python3 -m unittest discover -s tests        # проверка отгружаемого CSV
python3 src/drru/qa.py                        # проверки, с находками
python3 scripts/check_terms.py                # один термин, одно слово
python3 src/drru/build.py                     # корпус становится CSV
python3 scripts/fetch_fonts.py                # скачать пиксельные шрифты
python3 scripts/install.py --game "<path>"    # поставить в копию игры
python3 scripts/voice_audit.py                 # где перевод суше источника
```

Сама игра: `python3 scripts/screenshot.py --out work/shots/scene.png` снимает
окно запущенной игры, `scripts/click.py --at 960,515` кликает по нему, а
`scripts/send_keys.py --keys "{ENTER}"` набирает текст.

Пайплайну нужен эндпоинт модели. `src/drru/llm_client.py` читает его из
`DRRU_BASE_URL` (по умолчанию `http://127.0.0.1:8788/v1`) и `DRRU_MODEL`
(по умолчанию `minimax-m3`). Каждый вызов кэшируется в `work/cache/`, поэтому
повторный прогон стоит ноль, пока промпт не изменился.

Полный прогон:

```bash
python3 src/drru/extract_corpus.py --game "<путь к The Drifter>"
python3 src/drru/translate.py --stage bulk
python3 src/drru/translate.py --stage editorial
python3 src/drru/canonicalise.py
python3 src/drru/typography.py
python3 src/drru/polish.py
python3 src/drru/proofread.py
python3 src/drru/translate.py --stage manual
python3 src/drru/qa.py
python3 src/drru/build.py
```

Стадии пишут `work/corpus/*.jsonl`, и каждая читает файл, который написала
предыдущая: `bulk` → `edit` → `canon` → `typo` → `polish` → `final`. Сборка
читает `final`.

Стадия вычитки это проход чтением: каждая строка перевода читается против
английского источника, и модель называет строки, в которых сомневается. Каждую
находку читает человек, прежде чем что-то менять.

## Где что лежит

| Путь | Что это |
| --- | --- |
| `translation/Russian/translation.csv` | Файл, который читает игра. Артефакт. |
| `corpus/english.csv` | Английский корпус, с ключами и контекстом. |
| `src/drru/` | Пайплайн: корпус, перевод, редакторский проход, QA, сборка. |
| `src/voice/` | Код голоса, замороженный глоссарий, ручные правки. |
| `scripts/` | Установщик, загрузка шрифтов, проверки и аудит голоса. |
| `tests/` | Проверки, которые идут в CI. |
| `docs/` | Архитектура, голос перевода, глоссарий, замер ширины. |
| `work/` | Черновик: корпус, кэш, промежуточные проходы. Не в коммитах. |

## Ловушки

- **Игра ключирует текст парой (Character, ID).** Не английской строкой и не
  номером строки. Одна и та же английская строка встречается в нескольких
  местах, и перевод должен быть одинаковым во всех. `src/drru/canonicalise.py`
  следит за этим; запустить его после любой ручной правки дешевле всего, и так
  правило остаётся верным. Исключение это строка из одного слова: игра
  переиспользует одну и ту же строку для разных слов («Right» это «Верно» в
  одной сцене и «Вправо» в другой), и в самой строке ничего нет, что их
  различает.
- **Импортёру нужен UTF-8 с BOM и CRLF.** Без BOM кириллица приходит мусором,
  и это не опечатка: это кодировка.
- **Игра читает `translation.csv` из своего каталога**, а имя в последней
  колонке заголовка это имя, которое игра показывает в Options → Language.
- **Файл ассетов правится байт за байтом и никогда не пересобирается.** Ридер
  Unity теряет данные объектов, которые не разобрал: файл возвращается весом
  1,3 МБ вместо 30 МБ, и игра не запускается. Патч записывает байты данных
  шрифта поверх старых и сдвигает всё, что идёт после.
- **Кириллицу несут только семь текстовых шрифтов.** Остальные тринадцать идут
  на заголовки и иконки; у шрифта без строчных букв нет x-height, под который
  подгоняется масштаб, и получается шрифт, который игра не читает.
- **Код колонки это код языка.** Заголовок
  `Character,ID,File,Context,English,Русский`, и последняя ячейка это то, что
  игра показывает в Options → Language.
- **В шрифтах игры нет кириллицы.** Игра рисует русскую строку своим шрифтом
  рядом рун, так же, как рисует отсутствующий глиф. Установщик вписывает
  кириллические глифы; перевод без патча шрифтов нечитаем.
- **Сборка читает `final.jsonl`.** Сборка с более ранней стадии отгружает
  дефекты, ради которых существуют типографика и полировка.
- **Рассуждение модели стоит дорого.** `minimax-m3` тратит 186 секунд на батч
  из сорока строк с включённым рассуждением и 4,6 секунды с выключенным. По
  умолчанию клиент ставит `reasoning: {"effort": "none"}`.
- **Плейсхолдеры это `{0}`.** Их несут пятнадцать строк. Потерянный плейсхолдер
  это сломанная строка в игре, а не опечатка.
- **Английский источник это мерка.** Русская строка, в которой есть слово,
  которого нет в английской, это неверная строка. Стадия QA ищет латинские
  слова внутри русского предложения.
- **`MedCon` остаётся на латинице.** У него нет русского эквивалента, и
  читатель встречает его в английском тексте так же. `Mulindji` и
  `Herr Doktor` переведены: в тексте это «Мулинджи» и «Герр Доктор».
- **Один термин, одно слово.** Глоссарий говорит, что у имени одна русская
  форма, и текст обязан с ним соглашаться. `scripts/check_terms.py` читает
  строки, где встречается термин, и называет те, что переведены иначе; падежные
  формы расхождением не считаются, два написания одного имени считаются.
- **Термин, которого нет в глоссарии, переводится заново в каждом файле
  сценария.** Батчи не пересекают границы файлов сценария, поэтому каждый файл
  изобретает своё слово для термина: `phase-flip` написан пятью способами в
  пятнадцати файлах, `receptionist` четырьмя в шести. Число вариантов термина
  равно числу файлов, где он встречается. Заполняй глоссарий до перевода, а не
  после, включая термины, которых в тексте ещё нет.
- **Рассказчик говорит от первого лица, остальные от третьего.** Строка,
  которая начинается с английского `He` или `She` о ком-то другом, не должна
  начинаться с русского `Я`. Вычитка находит такие строки; это самый частый
  дефект в тексте.

## Стиль и правила безопасности

- **Комментарии объясняют *почему*, а не *что*.**
- **Никаких эмодзи**, ни в одном файле.
- **Не добавлять зависимость без причины, записанной рядом.**
- **Не удалять функциональность, похожую на намеренную.** Сначала спросить.
- **Голос фиксирован.** `docs/style-guide.md` это контракт с редактором; ручная
  правка, которая его ломает, будет исправлена следующим прогоном редакторского
  прохода.
- **Правка попадает и в CSV, и в `src/voice/manual_fixes.json`**, иначе следующий
  прогон пайплайна её отменит.
- **Файлы игры принадлежат разработчику.** Репозиторий хранит текст и
  инструменты. Установщик читает копию, которой владеет пользователь, и делает
  резервную копию всего, к чему прикасается.
- **Измеренная ширина русского текста меньше английской.** Медианное отношение
  0,85–0,96, а девяносто девятый перцентиль ниже 0,55; числа и способ их
  получения лежат в `docs/layout.md`.
