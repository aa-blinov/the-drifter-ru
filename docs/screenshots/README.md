# Снимки экрана

Снимки экрана игры на русском лежат здесь. Первый кадр снят в установленной
копии The Drifter после установки перевода и Ark Pixel:

- `camp-caption.png` — сцена у костра, подпись объекта «Билл греет руки у
  костра». Она помещается в одну строку; кириллические буквы читаются на фоне
  пиксельной сцены.

Параметры кадра: 1920×1080, версия игры `v1.1.5` (версия видна в главном меню),
установленный русский перевод и штатный размер шрифта. Сохранение и настройки
до и после проверки совпали по SHA-256.

Для полной визуальной проверки ещё нужны кадры, которые показывают:

- главное меню с выбранным русским языком;
- реплику персонажа с пиксельным шрифтом и кириллицей;
- экран персонажа, чтобы показать панель лора и ширину русской строки.

Визуальная проверка пятнадцати длинных строк остаётся незавершённой. К каждому
новому кадру нужно прилагать разрешение, настройки шрифта и сборку игры, из
которой он сделан.
