# Снимки экрана

Снимки экрана игры на русском, сняты в установленной копии The Drifter после
установки перевода (`install.py` с режимами по умолчанию: Ark Pixel в меню и
подписях, шрифт без сглаживания):

- `main-menu.png` — главное меню с русским языком; внизу справа видна версия
  игры `v1.1.5`.
- `camp-caption.png` — сцена у костра: подпись «Он без сознания, из уголка рта
  свисает тонкая струйка слюны» и реплика «Я не стану его трогать». Подпись
  помещается в одну строку.

Параметры кадров: 1920×1080, версия игры `v1.1.5`, установленный русский
перевод и штатный размер шрифта.

Для полной визуальной проверки ещё нужны кадры, которые показывают:

- экран персонажа с панелью лора и шириной русской строки;
- пятнадцать длинных строк из чек-листа.

К каждому новому кадру нужно прилагать разрешение, настройки шрифта и сборку
игры, из которой он сделан.

Список ключей, сцен и критериев проверки: `long-lines-checklist.md`.
