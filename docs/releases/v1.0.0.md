# Релиз 1.0.0

Первый выпуск русской локализации The Drifter: 9 803 строки перевода и
установщик, который вписывает кириллицу в шрифты игры.

- Весь текст игры переведён в один голос по глоссарию из 277 терминов.
- Кириллица вписана в двенадцать шрифтов игры: пиксельные получают Ark Pixel на
  своей сетке, гладкие контуры Play.
- Меню и подписи реплик рисуются пиксельным Ark Pixel целиком; `--no-pixel-ui`
  оставляет гладкий шрифт игры.
- HD-шрифт принудительно включён: строка языка 100000 равна `Y`. Переключатель
  «HD-шрифт диалогов» в настройках ничего не меняет, потому что штатные
  пиксельные шрифты игры с кириллицей нечитаемы.
- Установщик сам находит игру в библиотеках Steam.

## Как установить

1. Закройте игру. Нужен Python 3.9 или новее в `PATH`.
2. Скачайте **the-drifter-ru-v1.0.0.zip** из файлов этого релиза. Архивы
   `Source code` для установки не нужны.
3. Распакуйте архив и запустите `install.bat`. Установщик скачает шрифты, найдёт
   игру в Steam и сохранит оригинальные ассеты в `_ru_backup`.
4. В игре: **Options → Language → Русский**.

Подробности, ручная установка и откат есть в
[русском README](https://github.com/aa-blinov/the-drifter-ru/blob/main/README_ru.md).

## Проверки и ограничения

Пройдены тесты отгружаемого CSV и проверка оформления. Главное меню и реплики
проверены на экране в игре версии 1.1.5 при разрешении 1920 на 1080. Длинные
строки из `docs/screenshots/long-lines-checklist.md` на экране ещё не просмотрены.
